First public release of UCI Capture, a desktop viewer and recorder for Ultimate 64 video and audio streams.

- Live PAL and NTSC preview with optional runtime palette polling over FTP.
- MP4 or lossless MKV recording, with optional scanlines and a preselected output folder and filename.
- Clipboard snapshots and separate scanline controls for preview and recording.
- Windows x64 ZIP and Linux x86-64 archive. Extract the archive and run `UCI-Capture.exe` on Windows or `./UCI-Capture` on Linux.

See the bundled README and runtime palette guide for setup instructions and the third-party notices for bundled dependencies.
